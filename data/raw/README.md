# Raw Data

This directory contains the original, unmodified datasets.

## NASA C-MAPSS Dataset

Download from: https://data.nasa.gov/Aerospace/CMAPSS-Jet-Engine-Simulated-Data/ff5v-kuh6

Place the following files here:
- train_FD001.txt
- test_FD001.txt  
- RUL_FD001.txt
- train_FD002.txt
- test_FD002.txt
- RUL_FD002.txt
- train_FD003.txt
- test_FD003.txt
- RUL_FD003.txt
- train_FD004.txt
- test_FD004.txt
- RUL_FD004.txt

**Do NOT modify raw data files.**

All preprocessing outputs go to `data/processed/`.
