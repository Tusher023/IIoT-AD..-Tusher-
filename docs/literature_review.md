## Scope

This literature review covers recent research on:

1. Industrial IoT anomaly detection
2. Predictive maintenance
3. Unsupervised anomaly detection methods
4. Autoencoders for anomaly detection
5. LSTM Autoencoders for time-series anomaly detection
6. Isolation Forest and classical methods
7. C-MAPSS dataset studies
8. Remaining Useful Life (RUL) estimation
9. Early fault detection
10. Cross-condition generalization

## Review Protocol

### Search Strategy
- **Databases:** Google Scholar, IEEE Xplore, ScienceDirect, arXiv, Springer
- **Keywords:** "anomaly detection", "predictive maintenance", "autoencoder", "LSTM", "isolation forest", "C-MAPSS", "unsupervised", "IIoT", "remaining useful life"
- **Time range:** Primarily 2018–2026, with foundational works from earlier
- **Inclusion criteria:** Peer-reviewed papers, reputable conferences/journals, official documentation

### Documentation Standard

For each significant paper, record:

| Field | Description |
|-------|-------------|
| Citation | Authors, title, venue, year |
| Dataset | Dataset(s) used |
| Method | Core approach |
| Preprocessing | Data preparation steps |
| Evaluation | Metrics used |
| Key findings | Main results |
| Limitations | Weaknesses or gaps |
| Relevance | Connection to our research |

### Integrity

- Only include papers that can be verified as published.
- Mark any unverified citation with `[UNVERIFIED]`.
- Do not fabricate bibliographic information.
